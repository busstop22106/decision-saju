> 대상 파일: `question_report.dart` (질문 리포트 엔진), `saju_helpers.dart` (사주 헬퍼 발췌)

## (1) 카테고리별 초점 십성 매핑

| 카테고리 | 코드 매핑 | 전통 사주학 | 판정 |
|---|---|---|---|
| 재물(`wealth`) | 재성(정재·편재) | 재성 = 내가 극하는 오행 = 재물 | ✅ **확인** |
| 시험(`exam`) | 관성 \|\| 인성 | 관성 = 명예·직위, 인성 = 학문·합격 | ✅ **확인** |
| 자녀(`children`) | 식상(식신·상관) | 식상 = 내가 생하는 기운 = 자녀성 | ✅ **확인** |
| 사업(`business`) | 재성 | 재성 = 사업 자금·수익 | ✅ **확인** |
| 부업(`sidejob`) | 재성 | 재성 (부수입) | ✅ **확인** |
| 소송(`legal`) | 관성 \|\| 비겁 | 관성 = 법·관재, 비겁 = 경쟁 상대 | ✅ **확인** |
| 배우자(`marriage`/`reunion`) | `isSpouseStar` 사용 | 남명 재성·여명 관성 | ✅ **확인** (아래 (2)에서 상세) |
| 직장(`job`) | 관성 | 관성 = 직장·상관·조직 | ✅ **확인** |

> [!NOTE]
> 전통 사주학의 정설 매핑을 충실히 따르고 있습니다. 소송에 비겁을 포함한 것도 타당합니다 — 비겁은 경쟁자·분쟁 상대를 상징하여 소송 환경의 격화 여부를 볼 때 쓰입니다.

### 지적 사항

**#1 — 소송(`legal`)에서 비겁이 양날의 검인 점 미고려 · 심각도: 낮음**

현재 코드는 비겁도 관성과 동일하게 **양수(+) 기여**로 처리합니다. 그러나 전통 사주학에서 소송 시 비겁은 "분쟁이 격화될 수 있다"는 **주의 신호**이기도 합니다. 비겁이 들어올 때 무조건 긍정 점수를 주는 것은 "소송할 기운이 강하다 ≠ 이긴다"를 혼동할 수 있습니다. 비겁은 0점 또는 별도 경고 메시지가 더 정확합니다.

**#2 — 사업(`business`)에 관성 미포함 · 심각도: 중간**

전통 사주학에서 사업운은 재성(수익)뿐 아니라 **관성(규제·인허가·조직 통제력)**도 함께 봅니다. 특히 편관(七殺)은 사업가의 추진력·결단력을 의미합니다. 사업 카테고리에 재성만 보고 관성을 빠뜨린 것은 불완전합니다. `isWealthGod(god) || isOfficerGod(god)` 정도가 더 전통적입니다.

**#3 — 이사(`moving`)를 재성으로 매핑 · 심각도: 중간**

코드에서 `moving`은 재성으로 매핑되어 있습니다. 전통 사주학에서 이사·이동은 주로 **역마(驛馬)**와 **충(冲)**으로 판단하며, 십성 중에는 편인(변동)이나 식상(자유로운 움직임)이 더 관련됩니다. 재성은 이사 자금과 관련될 수 있지만 핵심 지표는 아닙니다. 역마를 이미 따로 처리하고 있으므로(섹션 4번), 초점 십성에서 재성을 부여하는 것은 "이사 자금의 흐름"으로 한정 해석해야 합니다. 주석으로 의도를 명확히 하거나, 식상·편인을 추가 고려하는 것이 좋겠습니다.

## (2) isSpouseStar에 천간을 넘기는 방식

```
// question_report.dart:88
return isSpouseStar(gender, dayMaster, stem);
```
```
// saju_helpers.dart:130-133
bool isSpouseStar(Gender gender, String dayMasterStem, String targetStem) {
  final god = tenGod(dayMasterStem, targetStem);
  return gender == Gender.boy ? isWealthGod(god) : isOfficerGod(god);
}
```

✅ **확인** — `isSpouseStar`는 `tenGod()`를 내부에서 호출하므로, 천간(stem)을 넘기는 것이 맞습니다. `tenGod()`가 일간과 대상 천간의 오행·음양 관계로 십성을 산출하고, 그 결과가 재성(남명)인지 관성(여명)인지 판정합니다.

### 지적 사항

**#4 — 배우자성에서 정재/정관만 볼 것인지 편재/편관도 포함할 것인지 · 심각도: 낮음**

현재 코드는 남명의 경우 정재·편재를 모두 배우자성으로, 여명의 경우 정관·편관을 모두 배우자성으로 봅니다. 전통 사주학의 정설은 **남명은 정재가 정실(正妻), 여명은 정관이 정부(正夫)**이고, 편재·편관은 편처·편부 혹은 애인을 의미합니다. 그러나 현대 감정에서는 둘 다 배우자 인연으로 넓게 보는 것이 일반적이므로 **앱 성격상 이 처리는 합리적**입니다. 다만 `reunion`(재회) 카테고리에서는 편재·편관을 별도로 강조하면 "옛 인연인지 새 인연인지" 뉘앙스를 줄 수 있습니다.

## (3) 역마·도화 사용

### 역마(驛馬)

```
// saju_helpers.dart:168-173
String travellingHorse(String dayBranch) {
  if ({'인', '오', '술'}.contains(dayBranch)) return '신';
  if ({'신', '자', '진'}.contains(dayBranch)) return '인';
  if ({'사', '유', '축'}.contains(dayBranch)) return '해';
  return '사'; // 해묘미
}
```

✅ **확인** — 삼합국 기준 역마 배치가 전통과 정확히 일치합니다.
- 화국(인오술) → 신(申)
- 수국(신자진) → 인(寅)
- 금국(사유축) → 해(亥)
- 목국(해묘미) → 사(巳)

### 도화(桃花)

```
// saju_helpers.dart:176-183
String peachBlossom(String dayBranch) {
  if ({'인', '오', '술'}.contains(dayBranch)) return '묘';
  if ({'신', '자', '진'}.contains(dayBranch)) return '유';
  if ({'사', '유', '축'}.contains(dayBranch)) return '오';
  return '자'; // 해묘미
}
```

✅ **확인** — 삼합국 기준 도화(咸池) 배치가 전통과 정확히 일치합니다.

### 지적 사항

**#5 — 역마를 일지(日支) 기준으로만 보는 점 · 심각도: 낮음**

전통 사주학에서 역마는 **연지(年支)**를 기준으로 보는 유파도 있고, 일지를 기준으로 보는 유파도 있습니다. 일지 기준은 널리 쓰이는 방법이므로 틀렸다고 할 수는 없지만, 주석에 "일지 기준 역마"임을 명시하면 좋겠습니다.

**#6 — 역마를 `moving`/`abroad`에만, 도화를 `reunion`에만 적용 · 심각도: 중간**

- **역마**: 직장 이동(이직 = `job`)에도 역마는 중요한 지표입니다. 전통적으로 역마가 동하면 직장 변동·이직·전근을 의미합니다. 현재 `job` 카테고리에서 역마를 전혀 보지 않습니다.
- **도화**: `marriage`(결혼) 카테고리에서도 도화는 새 인연·매력의 기운으로 의미가 있습니다. 재회에만 적용하고 결혼에 적용하지 않은 것은 아쉽습니다.

## (4) 건강을 부족한 오행 보충으로 보는 방식

```
// question_report.dart:237-250
if (categoryId == 'health') {
  final lacking = lackingElements(saju.elementCounts);
  for (final entry in {'올해': yearP, '이번 달': monthP}.entries) {
    final element = stemElement(entry.value.stem);
    if (lacking.contains(element)) {
      factors.add(_TopicFactor(8, '...부족한 오행을 채워줘 몸의 균형에 도움이 돼요.'));
    }
  }
}
```

### 지적 사항

**#7 — 건강을 오행 균형(부족 보충)으로만 보는 것은 과도하게 단순 · 심각도: 높음**

전통 사주학에서 건강은 다층적으로 봅니다:

1. **용신 득령 여부** — 건강의 핵심은 용신이 힘을 받는지입니다. 용신이 극(剋)을 받으면 건강이 위태롭습니다.
2. **일간의 신강/신약** — 신약한 사람에게 관성(나를 극하는 기운)이 들어오면 건강 압박이 됩니다.
3. **오행과 장부 대응** — 목(간·담), 화(심·소장), 토(비·위), 금(폐·대장), 수(신·방광). 단순히 부족한 오행이 채워지면 좋다가 아니라, 어떤 오행이 과다하거나 극을 받는지가 건강의 취약 부위를 결정합니다.
4. **충(冲)** — 건강에서 충은 사고·수술·급성 질환의 신호입니다. 현재 건강 카테고리에서 충을 보지 않습니다(일반 충은 3번에서 보지만, 건강 맥락의 해석이 누락).

현재 로직은 "부족한 오행이 들어오면 +8점"이라는 단일 기준만 있어서, **과다한 오행이 들어와 더 나빠지는 경우**나 **용신이 극을 받는 경우**를 포착하지 못합니다.

**#8 — 건강에서 천간(stem)만 보고 지지(branch)를 보지 않음 · 심각도: 중간**

`stemElement(entry.value.stem)`만 확인합니다. 지지의 본기 오행도 건강 판단에 영향을 줍니다. 예를 들어 세운 지지가 목(木)이면 간·담 계통에 영향을 줍니다.

## (5) 가족·기타 운세를 오늘의 결정 지수로 쓰는 방식

```
// question_report.dart:256-258
if (categoryId == 'family') {
  index = decisionIndex(saju, now);
}
```

### 지적 사항

**#9 — 가족 운세에 전용 로직이 없는 것은 아쉬움 · 심각도: 중간**

전통 사주학에서 가족은 육친(六親)으로 봅니다:
- **부모** = 인성(정인·편인)
- **형제·자매** = 비겁(비견·겁재)
- **자녀** = 식상(식신·상관)
- **배우자** = 남명 재성 / 여명 관성

가족 운세를 "오늘의 결정 지수(decisionIndex)"로 대체하면, 가족이라는 주제의 고유한 사주적 의미를 전혀 반영하지 못합니다. 가족 카테고리가 너무 넓어서 하나의 십성으로 대표하기 어렵다는 설계 판단은 이해하지만, 최소한 인성(부모)·비겁(형제)의 흐름 정도는 반영할 수 있습니다.

**#10 — `default` 카테고리(기타)도 같은 문제 · 심각도: 낮음**

`_isFocusGod`에서 `default: return false;`이므로 초점 십성이 없는 모든 카테고리는 충·합만으로 점수가 결정됩니다. 이 자체가 틀린 것은 아니지만(범용 흐름 지수), 사용자가 특정 주제를 기대할 수 있으므로 주석으로 의도를 명확히 하면 좋겠습니다.

## (6) 점수 가중치의 합리성

| 요인 | 점수 | 판정 |
|---|---|---|
| 대운 초점 십성 | +10 | ✅ 합리적 — 대운은 10년 단위의 큰 흐름이므로 가장 높은 가중치가 맞습니다. |
| 올해(세운) 초점 십성 | +8 | ✅ 합리적 — 1년 흐름으로 대운 다음의 중요도. |
| 이번 달(월운) 초점 십성 | +6 | ✅ 합리적 — 월 단위 소흐름. |
| 충(冲) | -8 | ✅ 합리적 — 충은 강한 주의 신호. |
| 합(六合·三合) | +6 | ✅ 합리적 — 순조로운 신호. |

### 지적 사항

**#11 — 대운·세운·월운 점수가 모두 단순 누적되는 구조 · 심각도: 낮음**

전통 사주학에서 대운과 세운의 관계는 단순 합산이 아닙니다. 대운과 세운이 서로 충하면 그 효과가 상쇄되거나 악화되고, 대운과 세운이 합하면 시너지가 납니다. 현재 코드는 대운-세운 간 상호작용(대운 천간 vs 세운 천간의 합·충)을 보지 않습니다. 간이 앱이라는 점에서 허용 가능한 단순화이지만, 전통적으로는 미흡합니다.

**#12 — 삼합을 육합과 동일 가중치(+6)로 처리 · 심각도: 낮음**

삼합(三合)은 세 지지 중 **두 개**만 만나는 반합(半合)인지, 세 개가 다 갖춰진 완전 삼합인지에 따라 힘이 다릅니다. 현재 `branchesTriple`은 두 지지만 체크하므로 사실상 반합입니다. 반합은 육합보다 약하게 보는 유파도 있으므로, 동일 가중치는 약간 관대합니다.

## (7) 로직 오류·누락된 만세력 요소

**#13 — 대운 지지를 충·합에서 보지 않음 · 심각도: 높음**

```dart
// question_report.dart:173 — 올해·이번 달만 충·합 체크
for (final entry in {'올해': yearP.branch, '이번 달': monthP.branch}.entries) {
```

대운(大運)은 가장 큰 흐름인데, 대운 지지와 일지의 충·합을 전혀 체크하지 않습니다. 대운 지지가 일지와 충하면 10년간의 큰 변동이고, 합하면 10년간 안정입니다. 이것이 빠진 것은 **중대한 누락**입니다.

**#14 — 형(刑)을 전혀 보지 않음 · 심각도: 중간**

전통 사주학의 삼형(三刑) — 인사신(무은지형), 축술미(지세지형), 자묘(무례지형) — 은 충 못지않게 중요한 흉신호입니다. 특히 소송(`legal`)과 건강(`health`)에서 형은 핵심 판단 요소입니다. 완전히 누락되어 있습니다.

**#15 — 원진(怨嗔)·귀문(鬼門) 미반영 · 심각도: 낮음**

재회·결혼 카테고리에서 일지와 세운·월운의 원진 관계(자미, 축오, 인사, 묘진, 술해, 유신)는 인연의 불화를 보는 지표입니다. 간이 앱이라 생략 가능하지만, 언급할 가치는 있습니다.

**#16 — 공망(空亡)을 전혀 보지 않음 · 심각도: 중간**

공망(空亡)은 일주 기준으로 빈 지지 2개를 산출하며, 그 지지가 세운·월운에서 나타나면 "기운이 비어 효과가 약해진다"고 봅니다. 재물·사업·시험 등의 결과가 기대에 못 미칠 수 있다는 주의 신호입니다. 전통 감정에서 공망은 기본 체크 항목인데 완전히 빠져 있습니다.

**#17 — 오행 카운트에 지장간(餘氣·中氣) 미포함 · 심각도: 낮음**

`saju_helpers.dart` 주석에 "천간 4 + 지지 본기 4 = 8자 카운트 (지장간 여·중기 미포함)"이라고 명시되어 있습니다. 간이법으로 일관성 있게 처리하고 있으므로 **의도된 단순화**로 봅니다. 다만 건강 오행 균형(#7)의 정확도를 떨어뜨리는 원인이 됩니다.

**#18 — 건강에서 천간만 보고 지지 본기를 안 봄 (재확인) · 심각도: 중간**

(#8과 연관) `lackingElements`로 부족 오행을 체크할 때, 세운·월운의 **천간 오행만** 확인합니다. 지지 본기 오행도 함께 봐야 더 정확합니다. 예: 올해가 갑인(甲寅)년이면 천간 갑=목이지만 지지 인=목이기도 해서, 목이 부족한 사람에게 더 강한 보충 효과입니다.

**#19 — 입춘 경계를 2/4 고정으로 처리 · 심각도: 낮음**

주석에 이미 "절입 시각은 연도별 천문표가 필요"하다고 고지하고 있으므로 **의도된 간이 처리**입니다. 실제 입춘은 해마다 2/3~2/5 사이에서 달라집니다. 간이 앱이라 허용 가능하지만, 경계일 출생자에게는 오차가 발생합니다.
