## 1. 시장조사 요약

### 1.1 시장 규모와 주요 앱

- 한국 점술 시장 규모는 약 1조 4,000억 원으로 추산되나 공식 통계는 아니다. 하드 지표로 보면 시장은 크고 성장 중이다.
- 점신(테크랩스): 누적 다운로드 1,900만, 2026-01 MAU 87만 명. 종합 슈퍼앱. 무료+광고, 광고 제거 월 2,900원, 상담 5,000~20,000원+.
- 포스텔러(운칠기삼): 누적 사용자 900만 표기, 2026-01 MAU 65.7만 명, 2024 매출 100억 원 돌파. 무료+광고, 포스 코인 충전·건별 소비(건당 3,000~20,000원 수준).
- 사주나루: 상담 중개 1위, 2024 매출 400억 원·영업이익 79억 원. 30초당 800원부터.
- 타이트사주(AI 신생): 월 매출 10억 원, MAU 100만, 재구매율 35%. 건별 리포트 20,000~49,500원.
- 만세력 천을귀인: 정밀 만세력 앱, Play 100만+ 다운로드. 설치 +24.8%·이용 +22.5%로 상위권 중 유일하게 두 지표 모두 성장.
- 찐사주(소형, 결정사주와 가장 가까운 경쟁자): 구슬 1개 990원부터. 양자택일·길일 조회·부모 궁합·결과 저장을 이미 한다.
- 소형 가족·작명군: 사주스튜디오(명식 보관함·작명 Pro), 작명도령(부모-자녀 궁합), 사주데이(990원 풀이·작명), my-k-saju(가족 사주 2~6명·귀인 지도).

### 1.2 사용자 불만 Top 5 (여러 출처에서 반복 확인된 것만)

1. **광고 과다** — 압도적 1위. "간단한 하루 운세 보는데 30초짜리 광고임?" (점신 리뷰)
2. **결제 유도·가격 불투명** — "한 번 보는데 만 원 충전에 한 번 더 보지도 못하고 또 충전" (포스텔러 리뷰)
3. **템플릿 결과·모순** — "리포트마다 말이 조금씩 다름", "내용 똑같은 것들도 많았다". 같은 앱 안에서 오늘 운세와 신년 리포트가 정반대 이야기를 하기도 한다.
4. **AI 번복·환불 분쟁** — AI가 답을 바꿨는데 "열람 후 환불 불가"만 반복. 결국 스토어에 정식 문제제기해 환불받은 사례가 있다.
5. **느림·저장 안 됨·어려운 용어** — "타로 같은 거는 계속 결과가 달라지니까 결과 저장하는 게 있었으면 좋겠어요", 만세력 설명이 공공문서처럼 어렵다는 불만.

추가로 20개 앱을 직접 써본 사용자 후기(네이버 블로그, 2025-01-22)에서 확인된 결핍: **아카이빙·검증 기능이 없다.** 헬로우봇은 유료결제 아카이빙이 잘 안 되고, 포스텔러는 앱 내 리뷰 기능이 없어 맞았는지 직접 체크해야 한다. 어느 앱도 "결정하고 30일 뒤 결과를 되묻는" 구조가 없다.

### 1.3 경쟁 현실 — 유저 획득이 가장 어려운 부분

- **유료 광고로 4,900원 상품을 팔면 회수가 안 된다.** 한국 Apple Ads CPI 중앙값 $1.84, 설치→유료 전환율 3% 가정 시 유료 고객 1명당 획득비 약 $61(약 8만 원). 4,900원 단건으로는 도저히 안 된다.
- **유일한 공짜 유통 채널은 작명별 크로스 프로모션**이다. 작명별 안에 "우리 가족 사주 보기" 배너·딥링크를 넣는 것. 이것만으로 초기 수백~수천 설치를 노린다.
- **ASO는 정면 키워드가 아니라 롱테일이다.** "사주" 한 단어로 1위하는 것은 불가능하다. "가족 궁합·아기 사주 작명·이사 길일·결정 사주" 같은 구체적 검색어로 파고든다.
- **시즌이 전부다.** 1월은 운세 앱 연중 최대 성수기. 출시 목표는 12월 중순~1월 초 신년 시즌. 이 시기를 놓치면 다음 기회는 1년 뒤다.

### 1.4 새로운 위협과 기회 — ChatGPT가 무료 운세를 잠식한다

- 2026-01 성수기 MAU가 점신 113만→87만 명(-23%), 포스텔러 67.8만→65.7만 명(-3%)으로 줄었다. 업계 해석은 "챗GPT로 새해 운세를 보는 사람이 늘어난 탓". 'GPT 사주' 검색량 전월 대비 +129% (2026-01).
- 반대로 정밀 만세력 앱(천을귀인)만 성장했다. "AI에게 물어보기 위한 정확한 원국 데이터"라는 새 수요가 생긴 것이다.
- 방어막은 두 가지다: ① 정확한 계산(만세력 정밀도), ② AI가 못 해주는 것(결정·가족·검증 루프).

### 1.5 제약 — 플랫폼 정책·법·소비자 이슈

- **Apple 심사 지침은 운세 앱을 포화 카테고리로 명시**한다. "의미 있는 차별화 또는 개선된 경험을 제공하지 않는 한 새로운 제출은 승인되지 않는다." 차별화를 스토어 설명·스크린샷·첫 화면에서 증명하지 못하면 출시 자체가 막힐 수 있다. 가장 큰 출시 리스크다.
- **결과를 보장하면 안 된다.** "이 날짜에 이사하면 성공한다", "연애운 80% 확률" 같은 단정·수치 보장 문구는 과장 광고·소비자 분쟁의 씨앗이다. 모든 리포트·결제 화면에 "재미·참고용이며, 중요한 결정은 이 결과만으로 내리지 마세요" 취지의 고지가 필수다.
- **환불은 결제 전에 고지해야 한다.** 디지털 콘텐츠는 열람 후 청약철회가 제한될 수 있다. 정책: 결과 생성·열람 전 100% 환불, 계산 오류(사주 자체가 틀리게 나온 경우)는 환불 사유로 인정.
- **개인정보:** 생년월일시·출생시각은 민감정보. 수집 최소로, 계산은 온디바이스(로컬) 우선, 서버 저장 없음이 원칙. 특히 자녀 정보 취급에 주의해야 한다.

## 2. 차별화 설계 — 조사 근거에서 어떻게 뽑았는지

### 2.1 핵심 방향 한 줄

**"작명별에서 이어지는 가족·결정형 사주"** — 결정 리포트를 돈 버는 상품으로, 가족·작명 허브를 유통·재방문의 축으로, 근거 공개와 광고 제로·단건 결제를 신뢰 약속으로 묶는다.

이 방향을 고른 이유: (1) 대형 앱이 안 하는(못 하는) 조합이다. (2) 개발자의 두 자산(작명별 유저, 만세력·81수리·가족 점수 엔진)을 동시에 쓴다. (3) 상담사·매일 콘텐츠·LLM 비용이 없어 밤 1시간으로 유지된다. (4) "오늘 운세 앱 하나 더"가 아니라서 Apple 심사에서도 차별화를 설명할 수 있다.

### 2.2 차별화 포인트 매핑표 — 불만/틈새 → 적용한 것 → 구현 상태

| 조사에서 확인된 불만·틈새 | 결정사주에 적용한 차별화 | 구현 상태 (2026-11-11 기준) |
|---|---|---|
| 광고 과다 (불만 1위) | **광고 SDK 없음.** 앱 전체 광고 제로. "이 앱에는 광고가 없습니다"를 스토어 첫 줄에 쓴다 | ✅ 구현 완료 (광고 SDK를 아예 안 붙임) |
| 결제 유도·가격 불투명 | **4,900원 정액 단건 1종, 추가 결제 없음.** 결제 전 "이 리포트에 포함되는 것" 목록 명시. 구독·코인 없음 | ✅ 구현 완료 (인앱결제 상품 ID `decision_report_4900`, 결제 전 고지 다이얼로그) |
| 템플릿·모순 불신 | **근거 3줄 공개** (용신·오늘 일진·대운 흐름). 모든 리포트를 단일 계산 원본(같은 만세력·용신)에서 뽑아낸다. "같은 계산에서 나온 결과입니다" 표시 | ✅ 구현 완료 (결정 리포트 근거 3줄, `evidenceLines`) |
| 아카이빙·검증 결핍 (어느 앱도 안 함) | **결정 기록 + 30일 뒤 되물음.** 결정을 저장하고 30일 뒤 "그 결정, 어떻게 됐어요?"라고 되물어 결과를 기록에 붙인다. 재방문·재구매의 엔진 | ✅ 구현 완료 (결정 일지 화면, 홈 되물음 배너, `dueFollowUps`) |
| 구체성 부족 (돌려 말하기) | **날짜를 구체적으로 적는다.** "좋은 시기가 옵니다"가 아니라 "30일 중 길일 3개"를 날짜와 함께 제시. 단, "참고용·결과 보장 없음" 고지는 유지 | ✅ 구현 완료 (길일 3개 + 30일 길일 달력 뷰, 목적별 필터) |
| 저장 안 됨·입력 소실 (점신 리뷰 기능 오류 23%) | **로컬 저장 견고성 테스트.** 손상된 데이터가 와도 앱이 안 죽고 좋은 항목만 남김. 가족 보관함·결정 기록 상한·삭제·재시작 유지 테스트 | ✅ 구현 완료 (견고성 테스트 14개, 전체 테스트 56개 통과) |
| 어려운 용어 | **용어 한 줄 해설.** 십신·용신·대운·공망 등 17개 용어를 60자 이내로 풀이. 만세력 화면 용어 옆 (?) 버튼 | ✅ 구현 완료 (용어집 17개, 만세력 화면 (?) 버튼 + 앱바 용어집 진입) |
| 점수·요약 먼저가 중요 (20개 앱 후기) | **결론·점수 먼저 구조.** 결정 리포트 맨 위에 "결론 1줄 + 결정 지수(점수)", 홈 맨 위에 "오늘의 결정 지수" 카드. 상세는 뒤에 둔다 | ✅ 구현 완료 (홈 오늘의 결정 지수 카드, 리포트 결론·지수 최상단) |
| 공유가 곧 유통 | **결과 저장·공유.** 리포트 결과를 이미지 카드(PNG)로 저장·공유. 시스템 공유 시트에서 카카오톡 선택 가능 | ✅ 구현 완료 (공유용 리포트 카드, 갤러리 저장, 텍스트 공유). 카카오톡 전용 SDK 공유는 미구현 (카카오 개발자 콘솔 네이티브 앱 등록 필요) |
| 신년 시즌 성수기 | **신년 운세 (올해의 결정형).** "올해의 운세" 일반형이 아니라 "올해 결정하기 좋은 달·피할 달"을 담은 결정형 신년 리포트 | ✅ 구현 완료 (연평균 결정 지수, 좋은 달 상위 3·피할 달 하위 2, 월별 지수 바) |
| 유일한 공짜 유통 채널 | **작명별 딥링크 양방향.** 결정사주 → 작명별 열기 (없으면 스토어로), 작명별 → 결정사주 진입 시 가족 보관함 탭으로 | ✅ 결정사주 쪽 구현 완료. 작명별 쪽 작업(스킴 등록 + "결정사주로 이어보기" 버튼)은 별도 진행 필요 |
| AI 번복·환불 분쟁 | **AI 자유 채팅 없음.** 규칙 기반 결정론적 엔진만 사용. 결제 전 고지(참고용·결과 보장 없음·계산 오류 시 환불) | ✅ 구현 완료 (정책 문서 4종: 재미·참고용 고지·환불정책·개인정보처리방침·이용약관) |
| 만세력 정밀도 격차 (천을귀인 대비) | 대운·세운·일진 달력, 십신 상세 — **2순위**로 미룸. 간이 대운만 엔진에 있음 | ⏳ 2순위 (출시 후 1~2개월) |
| AI 시대의 만세력 | **AI 프롬프트 내보내기** (ChatGPT·Gemini용 프롬프트 자동 생성) — 천을귀인이 증명한 방식. LLM 비용 없이 구현 가능 | ⏳ 2순위 |
| 가족 시각화 격차 (my-k-saju·사주스튜디오 대비) | 가족 오행 비교·귀인 지도, 쌍별 궁합 자유 선택 UI, 보관함 상한 3명 → 6명 검토 | ⏳ 2순위. 현재 보관함은 최대 3명, 가족 궁합 요약만 있음 |

### 2.3 안 하기로 한 것 (하지 않는 것이 전략이다)

| 상담사 연결 | 사주나루·천명의 영역. 1인 개발자 불가 + 천명은 역성장 중 |

### 2.4 가격 포지션

- 4,900원은 990원 앱(찐사주·사주데이)보다는 비싸고, 29,900원 리포트(타이트사주)보다는 싸다. "990원보다 깊고, 29,900원보다 싸다"는 중간 포지션이다.
