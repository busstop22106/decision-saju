# 결정사주

결정할 때 보는 사주 — 가족·결정형 사주 앱.
"오늘의 운세 앱 하나 더"가 아니라, 가족 사주 + 결정 리포트에 특화된 앱이다.
작명별에서 이어지는 새 앱으로, 작명별의 만세력 엔진과 유저를 유통 채널로 쓴다.

## 콘셉트

- 유료 상품 1종: 결정 리포트 일회성 4,900원 (A/B 양자택일 결론+근거 3줄, 30일 길일 3개, 오늘 피할 것 1개, 결정 기록→30일 뒤 되물음). 구독 없음, 광고 없음.
- 무료: 만세력 사주팔자 + 오늘 운세 3줄(광고 없음) + 가족 보관함 최대 3명.
- 연결: 가족 궁합 요약(부부·부모-자녀 중 1쌍 무료) + 작명별 딥링크.
- 신뢰 장치: 모든 리포트 하단에 근거 3줄(용신·일진·대운) + "같은 계산에서 나온 결과입니다" + 결과 저장·공유.
- 정책 최소 세트: 재미·참고용 고지, 환불정책(열람 전 100%, 계산 오류 시 환불), 개인정보처리방침·이용약관.
- 넣지 않음: 상담사 중개, 구독, AI 자유 채팅, 타로·관상 확장, 광고 SDK.

## 엔진 재사용 (작명별에서 가져옴, 동작 변경 없는 이동)

- `lib/engine/saju.dart` — 간이 만세력·용신/희신 계산 (`computeSaju`), 그대로 복사.
- `lib/engine/compat.dart` — 가족 궁합 채점 (`MemberCompat`), 그대로 복사.
- `lib/models.dart` — 필요한 모델만 옮김 (Gender, BabyInfo, SajuPillar, SajuResult, HanjaPick). 이름 짓기 전용 모델(SurnamePick, SharedBaby, DimensionGrade, DimensionScore, NameAnalysis)은 제외.
- 가져오지 않음:
  - `scoring.dart` — 81수리·한자·랭킹 기반 이름 채점이라 결정사주와 무관. 결정 리포트의 근거 점수화는 saju.dart의 용신/오행 데이터로 새로 만든다.
  - `reason_line.dart` — 이름 추천용 근거 문장(`recommendReason(NameAnalysis)`)이라 그대로 못 쓴다. 결정 리포트의 근거 3줄(용신·일진·대운)은 새로 만든다. 단, "계산 결과가 뒷받침하는 것만 문장으로 쓴다"는 원칙은 그대로 따른다.
  - `generator.dart`·`best_hanja.dart`·`hanja_order.dart` — 이름 생성 전용. 이름은 작명별 딥링크로 연결.
- 새로 만들 것: 30일 길일 계산(만세력 일진 기반 확장), 결정 기록(로컬 저장 + 30일 뒤 되물음), 결정 리포트 화면·결제 흐름(인앱결제 일회성).
- TODO: `GenderX` label이 '남아'/'여아'라 성인 가족 구성원에는 맞지 않는다. 가족 구성원 입력 화면을 만들 때 남성/여성 표기로 바꿀 것. `BabyInfo`의 성씨 필드는 사주 계산에 안 쓰이지만 이동 시 그대로 뒀다 — 가족 구성원 모델로 정리할 때 함께 손볼 것.

## 코드 규칙 (작명별과 동일)

- `lib/engine/`은 순수 Dart만 (Flutter import 금지). 계산·채점·사주·궁합 로직은 전부 여기.
- `lib/screens/`은 UI만, `lib/services/`는 플랫폼·결제·저장소, `lib/data/`는 정적 데이터.
- 화면끼리 로직 import 금지. 공유 위젯은 `lib/widgets/`로.
- 상태 관리는 setState 유지.
- 리팩토링 원칙: 동작 변경 없는 이동만 한 번에 한다. 이동 후 `flutter analyze` 클린 + 테스트 통과를 확인한다.

## 제약·리스크

- Apple 심사: 운세 앱은 포화 카테고리로 명시돼 "의미 있는 차별화" 없이는 신규 제출 승인 안 함 — 가장 큰 출시 리스크. 차별화(가족·결정 특화, 광고 제로, 근거 공개)를 스토어 설명에 명시할 것.
- 결과 보장 금지 ("80% 확률"식 단정 문구 금지), 재미·참고용 고지 필수.
- 전자상거래법상 디지털 콘텐츠 열람 후 환불 제한 가능 — 결제 전 고지·계산 오류 시 환불 명시가 분쟁 예방.
- 생년월일시는 민감정보로 취급 주의. 계산은 온디바이스, 서버 저장은 선택사항으로.
- 유저 획득: 유료 광고는 회수 안 됨 (한국 Apple Ads CPI 중앙값 $1.84, 전환율 3% 가정 시 유료 고객당 약 $61 vs 4,900원 상품). 채널 순위: ① 작명별 크로스 프로모션 ② 롱테일 ASO(가족 궁합·아기 사주·이사 길일) ③ 12~1월 시즌 숏폼·SEO.
