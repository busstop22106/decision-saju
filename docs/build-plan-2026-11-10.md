## 1. 결정 리포트 유료 흐름 (4,900원 일회성) ✅ (2026-11-10, 커밋 a27f84cf)

- **목표:** "결정할 때 켜는 앱"의 핵심 상품. 결론 1줄 + 결정 지수(점수)를 맨 위에, 근거 3줄, 30일 길일 3개, 오늘 피할 것 1개.
- **포함할 것:**
  - 결정 엔진 (`lib/engine/decision.dart`, 순수 Dart): 오늘의 결정 지수(0~100) 계산, A/B 양자택일 판정(사주 흐름상 유리한 쪽), 30일 길일 계산(일진 기반).
  - 결정 리포트 화면 (`lib/screens/decision_report_screen.dart`): 결론 1줄 + 결정 지수 맨 위 → 근거 3줄(용신·일진·대운) → 30일 길일 3개 → 오늘 피할 것 1개.
  - 결제 전 고지 화면: "참고용·결과 보장 없음·계산 오류 시 환불" + 포함 목록 명시("추가 결제 없음·4,900원 정액").
  - 결정 주제 선택: 이직·이사·결혼·개업·출산·기타 (A안/B안 입력).
- **구현 완료:**
  - 결정 엔진 (`lib/engine/decision.dart`): 오늘의 결정 지수(0~100), A/B 양자택일 비교, 30일 길일 상위 3개, 간이 대운(순행/역행·시작 나이·현재 대운 간지), 근거 3줄(용신·일진·대운), 오늘 피할 것 1줄. 일주 기준일 2000-01-01 무오일 — computeSaju와 교차 검증됨.
  - 결정 리포트 화면 (`lib/screens/decision_report_screen.dart`): 주제 선택(이직/이사/결혼/개업/출산/기타) + A/B 입력 + 날짜 선택 → 결제 전 고지 다이얼로그(포함 목록·4,900원 정액·참고용·환불 고지) → 리포트 화면(결론+지수 맨 위, 점수 바, 근거 3줄, 길일 3개, 피할 것 1개, 결정 기록 저장 버튼).
  - 결정 기록 저장 (`lib/models.dart` DecisionRecord + `lib/services/decision_store.dart`): SharedPreferences `decision_records_v1`, 30일 경과 판정 + 되물음 답 저장.
  - 홈 '결정 리포트' 카드의 '만들기' 버튼이 폼 화면으로 연결됨.
  - 테스트 16개 추가 (총 28개 통과), analyze 클린 (기존 info 1건만).
- **남은 것:** 실제 인앱결제 연결은 8번 항목에서. 리포트 화면 상단에 "미리보기 — 결제 연동 전" 안내가 있음.

## 2. 결정 기록 + 30일 뒤 되물음 ⬜

- **목표:** 아카이빙·검증 결핍을 메우는 유일한 차별점. 어느 경쟁 앱도 안 한다.
- **포함할 것:**
  - 결정 기록 저장 (`lib/services/decision_store.dart`, SharedPreferences): 결정 내용·선택(A/B)·결정일·리포트 요약.
  - 결정 일지 화면: 지난 결정 목록 + 결과 기록.
  - 30일 뒤 되물음: "그 결정, 어떻게 됐어요?" (인앱 배너 + 푸시는 2순위에서).
  - 되물음 답(잘 됐어요/아직 몰라요/안 됐어요)을 기록에 붙임.
- **완료 조건:** 기록 저장·불러오기·30일 경과 판정 테스트 통과.

## 3. 30일 길일 달력 뷰 ⬜

- **목표:** 결정 리포트의 길일 3개와 같은 데이터로 달력 뷰 제공.
- **포함할 것:**
  - 길일 달력 화면 (`lib/screens/lucky_days_screen.dart`): 30일 달력에 길일 표시, 날짜 탭 시 그날의 길흉 한 줄.
  - 목적별 필터: 이사·결혼·개업·이직.
  - 결정 리포트의 길일 3개와 같은 엔진 데이터 사용.
- **완료 조건:** 달력 뷰에서 길일 3개와 일치 확인 + 테스트 통과.

## 4. 신년 운세 (올해의 결정형) ⬜

- **목표:** 1월 성수기 필수. "올해의 운세" 일반형이 아니라 "올해의 결정"형으로 차별화.
- **포함할 것:**
  - 신년 결정 리포트 화면: 올해 결정하기 좋은 달·피할 달, 올해의 결정 지수 월별.
  - 홈에 12월~1월 시즌 진입 카드.
- **완료 조건:** 2027년 기준 신년 리포트 표시 확인 + 테스트 통과.

## 5. 결과 저장·공유 (이미지 카드·카톡) ⬜

- **목표:** 공유는 곧 유통이다. 전원 경쟁 앱이 한다.
- **포함할 것:**
  - 결과 이미지 카드 (PNG) 다운로드: 결정 리포트·오늘 운세·궁합 결과를 이미지로 저장.
  - 카카오톡 공유: 작명별·주식 퀴즈에서 쓴 카카오 SDK 방식 참고 (실제 전송은 폰에서 확인).
- **완료 조건:** 이미지 카드 생성 확인 + 카톡 공유 버튼 동작 확인.

## 6. 결론·점수 먼저 구조 (오늘의 결정 지수) ⬜

- **목표:** 백점 2022·점신식 대시보드가 증명. 길고 자세한 것은 뒤에 두는 것이 기억에 남는다.
- **포함할 것:**
  - 홈 첫 화면에 "오늘의 결정 지수" 요약 점수·상태를 맨 위에.
  - 오늘 운세 3줄은 그 아래에.
  - 결정 리포트 맨 위에 결론+지수 (1번과 연결).
- **완료 조건:** 홈에서 3초 안에 "오늘 결정하기 좋은 날인가" 답이 보이는지 실기기 확인.

## 7. 용어 한 줄 해설 ⬜

- **목표:** 경쟁 앱 공통 불만 "어려운 용어" 해결. 평점 방어.
- **포함할 것:**
  - 용어 해설 데이터 (`lib/data/glossary.dart`): 용신·희신·십신·대운·세운·공망·일진 등 한 줄 풀이.
  - 만세력 화면의 용어 옆에 (?) 탭 시 해설 표시.
- **완료 조건:** 주요 용어 10개 이상 해설 + 화면 표시 확인.

## 8. 결제(인앱결제) + 정책 문서 ⬜

- **목표:** 4,900원 정액·추가 결제 없음의 투명성. 결제 전 고지 필수.
- **포함할 것:**
  - 인앱결제 연동 (`in_app_purchase` 패키지, 상품 ID `decision_report_4900`): 구매·복원 흐름. Play Console 상품 등록은 사용자가 직접 (앱 내 안내 문구 포함).
  - 정책 문서: 재미·참고용 고지, 환불정책(열람 전 100%, 계산 오류 시 환불), 개인정보처리방침·이용약관 (앱 내 화면 + 스토어 링크용).
- **완료 조건:** 결제 흐름 화면 완성 + 정책 문서 3종 앱 내 표시. 실제 결제는 Play Console 상품 등록 후 실기기 확인 (사용자 몫).

## 9. 작명별 딥링크 ⬜

- **목표:** 크로스 프로모션은 유일한 공짜 유통 채널이다.
- **포함할 것:**
  - 결정사주 → 작명별 딥링크 (앱 링크 + 스토어 폴백).
  - 작명별 → 결정사주 딥링크 (작명별 쪽 작업은 작명별 채팅에서 별도 진행, 여기서는 결정사주 쪽 수신 처리만).
  - 작명별에서 온 사용자(부모·가족 맥락)는 가족 보관함을 먼저 보여주는 진입 분기.
- **완료 조건:** 딥링크 수신 처리 + 스토어 폴백 동작 확인.

## 10. 안정성·저장 견고성 테스트 ⬜

- **목표:** 점신 리뷰 불만족 62%·기능 오류 23%의 교훈. 입력 정보 소실·결제 에러·앱 안 열림은 절대 안 된다.
- **포함할 것:**
  - 가족 보관함·결정 기록 로컬 저장 견고성 테스트 (손상 데이터·상한·삭제).
  - 입력 정보 소실 재현 테스트 (앱 재시작 후 보관함 유지).
  - 전체 테스트 통과 + analyze 클린 + 맥북 실기기 최종 확인.
- **완료 조건:** 전체 테스트 통과 + 실기기 확인 완료.
