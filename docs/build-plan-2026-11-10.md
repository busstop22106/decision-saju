## 12. 카테고리별 A/B 채점 엔진 전면 개편 ✅ (2026-11-12)

- **배경:** 기존 폼은 A안/B안에 날짜를 각각 붙이고 날짜 점수로만 비교했다. 그래서 날짜가 같으면 점수가 똑같이 나와 "비슷함"이 되고, "지금 당장 A vs B"라는 사용 상황에는 답을 못 줬다. 사용자가 "엔진을 전면 수정"하라고 지시.
- **설계:**
  - **선택형 (이직·이사·결혼):** 고정 A/B 문구. 이직 = 지금 회사에 남기 / 다른 회사로 이직하기, 이사 = 지금 집에 있기 / 이사하기, 결혼 = 지금 사람과 결혼하기 / 새로운 인연 찾아보기. 내 사주 + 세운(올해) + 월운(이달) + 대운으로 채점한다. 날짜를 쓰지 않는다.
  - **날짜형 (개업·출산·기타):** A/B가 날짜라 기존 날짜 점수(scoreDay)로 비교한다. 개업은 재성 기운이 있는 날 +5점, 출산은 식상 기운이 있는 날 +5점. 기타는 자유 입력 + 날짜(기존 동작 유지).
  - **채점 요인 (선택형):** 대운·세운·월운 천간의 십성(관성=이동·인성=유지, 결혼은 배우자성만), 역마(이직·이사), 일지 충·합/삼합, 도화(결혼), 대운 교체 해(이직·이사), 용신(월간). 50점 중립 기준 + 가산, 0~100 클램프, 10점 차이 기준(기존 compareOptions와 동일).
  - **만세력 헬퍼 (`lib/engine/saju.dart`):** `yearPillarFor`·`monthPillarFor`(입춘·오호둔법, computeSaju가 같은 함수를 쓰도록 리팩토링), `tenGod`·`isSpouseStar`(남명 재성·여명 관성), `branchesCombine`(육합)·`branchesTriple`(삼합), `travellingHorse`(역마)·`peachBlossom`(도화).
  - **새 엔진 (`lib/engine/decision_options.dart`):** `configForTopic`, `scoreChoiceOptions`, `scoreTimingOptions`. `DecisionComparison`에 `reasons` 목록 추가.
  - **화면:** 폼은 카테고리별로 입력이 바뀐다(선택형은 고정 카드, 개업·출산은 날짜만, 기타는 글자+날짜). 리포트는 선택형일 때 "이렇게 판단했어요" 근거(요인+점수)를 보여주고 추천 선택지의 점수를 크게 보여준다.
- **Antigravity 코드 리뷰 (2026-11-12, Claude Opus 4.6):** 전문 `docs/code-review-2026-11-12-options.md`. 십성·육합·삼합·역마·도화·배우자성·대운 방향 전부 전통 사주학과 일치 확인. 지적 6건 중 1건은 이미 해결됨(공유 함수 구조), 1건 수정(reasons 표시), 2건은 테스트로 보장(대운 전환·23시 보정), 2건은 알려진 한계·의도된 설계로 수용(입춘 2/4 고정, 50점 중립 기준, 결혼 일지 충 해석).
- **테스트:** 신규 24개 (십성·지지 관계·연월주·설정·선택형 채점·날짜형 채점·대운 교체·23시 보정). 전체 120개 통과, analyze 클린 (기존 info 1건만).
